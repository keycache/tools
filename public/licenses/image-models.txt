Watermark Removal
-----------------
Model: foduucom/Watermark_Removal
Publisher: FODUU AI
Model card authors: Nehul Agrawal and Priyal Mehta
Source: https://huggingface.co/foduucom/Watermark_Removal
Revision: e75b840dc74b7d213833c4ef5cc1cea63c19e81d
License declaration: Apache-2.0 (model-card metadata).
Original weight SHA-256:
dfceb0199f80877802c6f0c5abf412f39ee82a634cbbcf072d05ce7c06e33d3b

Changes made for this application: converted the PyTorch state_dict to a fixed
1x3x256x256 ONNX graph using the published architecture. Learned weights are
rounded to FP16 for storage and cast back to FP32 for computation, inputs, and
outputs, preserving browser CPU/WASM compatibility. Pooling/upsampling are
expressed as functional operations. No retraining or integer quantization.
Inference clamps output to [0,1], supports repeated passes, and resizes the
final reconstruction to the input aspect ratio within 256x256.

The publisher describes a custom training dataset without comprehensive
provenance. The license declaration is not a warranty of third-party rights.
Edit only images you own or have permission to modify.

Image Upscaling
---------------
Model: Swin2SR classical super-resolution x2
Authors: Conde et al.
Original model: https://huggingface.co/caidas/swin2SR-classical-sr-x2-64
Original code: https://github.com/mv-lab/swin2sr
ONNX conversion: Xenova
Source: https://huggingface.co/Xenova/swin2SR-classical-sr-x2-64
Revision: 71e28a83cfb61f5dc95bafdeebf2815167914f2b
License: Apache-2.0 (original checkpoint, ONNX model cards, and upstream code).
Distributed ONNX SHA-256:
6dde3fe2440543ccae7c40d175609f83c18aeaa3d8456745c4329ef97ae744bd

The FP32 ONNX graph is redistributed without changes. This application's
inference uses contextual tiles and symmetric padding. 3x enlargement uses
two 2x passes followed by browser resampling; 4x uses two 2x passes. Browser
resampling is not guaranteed to match the Python/Pillow Lanczos implementation.
